# Research

I use AI to get from “what if?” to a working test while I'm still excited about the question. Can I grow a network without changing its predictions? Can I sample exactly while reading only a fraction of a model's output weights? What should a memory keep before it knows the question?

I'm following those questions through 54 projects on learning, efficient computation and their mathematical limits. I've published some as working implementations and completed studies; others are in progress or waiting to be built. I like being able to chase more of them far enough to find out.

I build around exact references, recoverable experiments, strong baselines and complete resource costs. When a simpler method wins, I keep that in the record. That's often where I learn the most.

I link each project name to my research brief and each **Published** status to its implementation. I leave result cells blank until I have study or pilot findings to report; **Planned** entries are ideas I still want to test. For published projects, I use the current results, which can supersede the original brief.
